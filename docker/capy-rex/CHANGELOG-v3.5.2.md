# 3.5.2（2026-11-21）

Docker 和 CF 同一份代码，两边都是 3.5.2。数据库结构、模块/合集/首页 ID、分享名、公开地址、备份格式（format 1–8）都不变。

## 修复

- **复制链接在 HTTP 地址上报错**：用 `http://NAS-IP:8083` 打开时浏览器没有剪贴板接口，原来点「复制」会直接报错、什么都不提示。现在改用备用方式复制；还是不行时，弹出对话框显示链接，长按即可手动复制。所有复制按钮都适用（模块、合集、订阅、图标、首页）。
- **iPhone 上首页「复制分享链接」失败**：原来要先等服务器返回链接再复制，iOS Safari 会拒绝，提示「复制失败」。现在已分享的首页直接复制；第一次分享时，点下确认就开始复制。
- **CF：大首页包和头像可能超过一行 2 MB 的限制**：首页包和头像存在同一行，两者都接近 1 MB 时会写入失败。现在超过 256 KB 的内容就分片存储。
