# Capy/Rex Widgets Hub V1.1

作者：芜湖。发布日期：2026-11-27。

## 修复内容

- `/user` 为公开组件页；`/admin` 为开发者与管理员统一登录及工作台。管理员登录后可点击“模块管理台”进入 `/admin/manage`。
- 旧 `/`、`/index.html`、`/community` 以 308 跳转到 `/user`；旧社区 JS/CSS 地址及全部 API 保持兼容。开发者需将后台书签改为 `/admin`。
- 社区页面 CSP 增加同源图片和 manifest 许可，修复局域网也缺图标的问题。继续限制脚本、连接及表单为同源，上传 HTML/SVG 继续使用沙箱。
- NAS 模式通过明确配置的 Host→origin 映射识别 HTTPS，修复反代登录来源不匹配及错误的 HTTP 分享地址。保留 CSRF 检查、角色权限和登录限速。拒绝未列入白名单的 Host，不接受伪造转发头切换 origin。
- 首次网页/终端初始化、管理员修改密码、开发者创建/重置/修改密码统一 8–256 字符。没有重置任何现有密码，也没有创建生产测试账户。

## Lucky 必改项

两个域名分别保留原有 HTTPS 证书和前端域名，后端均填写：

`http://192.0.2.10:8080`

后端不要附加 `/community`、`/user`、`/admin`，不添加路径前缀，不剥离前端路径。反代请求保留客户端原始 Host（your-domain.example.com 或 your-domain.example.com），不要改成后端 IP。应用不依赖 X-Forwarded-Host / X-Forwarded-Proto。端口保持 8080。

修改后访问：

- 主域公开页：https://your-domain.example.com/user
- 主域后台：https://your-domain.example.com/admin
- 备用域公开页：https://your-domain.example.com/user
- 备用域后台：https://your-domain.example.com/admin
- 内网公开页：http://192.0.2.10:8080/user
- 内网后台：http://192.0.2.10:8080/admin

不同域名的登录 Cookie 独立，请在实际使用的域名登录。HTTPS Cookie 设置 Secure；内网 HTTP Cookie 不设置 Secure，均保持 HttpOnly 和 SameSite=Strict。公开链接使用当前已允许的访问域名，备用域不会强制跳转主域。

本机配置：PUBLIC_URL=https://your-domain.example.com；ALLOWED_ORIGINS 包含备用 HTTPS 域名、192.0.2.10:8080、127.0.0.1:8080、localhost:8080 三个 HTTP origin。换域名或端口时同步更新，随后 docker compose up -d。不要把公开与内网两个协议配置成同一 Host，以免协议歧义。

## 部署与回退

先执行 `docker compose exec hub node nas/backup.mjs` 生成完整 SQLite 在线备份，再替换源码，保留 `.env` 和 `data/`，运行 `docker compose up -d --build`。不要删除数据库、不要重新初始化、不要执行 down -v。

本次源码快照在 `/path/to/capy-rex-pre-V1.1-20261127-100821.tar.gz`；原环境配置在 `/path/to/capy-rex-pre-V1.1.env`（仅本机，权限 600，禁止分享）；数据库快照位于 `data/backups/nas-full-2026-11-27T02-08-23-535Z-98be61a9.sqlite`。另保留镜像 `capy-rex:V1-rollback`。

如需回退应用，先完整备份当前数据并停止 hub，恢复快照中的源码和 compose.yaml，恢复本机原环境配置，再将 compose 的 image 改为 capy-rex:V1-rollback 并使用 `docker compose up -d --no-build`。本次没有数据结构迁移，常规回退应保留当前 data，避免丢失升级后新增内容。只有明确需要回到旧数据时才按离线恢复流程操作完整数据库备份。不要同时运行两个实例写同一库。

ZIP 不含 `.env`、数据库、备份、凭据或生产账号信息；首次安装使用 `.env.example` 按自身主机修改。现有安装不得覆盖 `.env` 或 `data/`。
