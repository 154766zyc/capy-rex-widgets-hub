## 数据兼容

沿用 SQLite 与数据库内文件存储；不新建数据库表，不改 format 7。订阅摘要 `icon_url` 为上游头像，`custom_icon_url` 为本站缓存；同步从实时 SQL 合并自定义图标，编辑来源和暂停/恢复不丢失覆盖。

图标清理同时保护合集和订阅引用；恢复前校验订阅缓存图标存在。订阅图标接口使用 revision 与 expected_icon_url 乐观锁，最终写入通过 Docker 短事务且重新校验清空/恢复 epoch。下载期间不占写事务。

保留既有模块 ID、合集 ID/slug、历史别名、模块分享别名、文件名与公开路径。新跨组动作只修改分组；不会自动批量改名、删模块或调整合集顺序。原下载策略、可信来源、调度与密码沿用。

Rex 原生客户端播放与缓存刷新不在本次验证范围。
