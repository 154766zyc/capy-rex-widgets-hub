# 3.5.1 本地修复与预览记录

本文件记录本地修复及页面预览。用户已确认并指定发布为 3.5.1；最终部署和镜像验证状态见 `NAS-DEPLOYMENT-v3.5.1-20261121.md`。

## 改动

- 订阅页只保留「全部同步」与右对齐的排序控件；统一 44px 点击高度、固定按钮宽度，进度独立显示，排队开始即进入禁用/忙碌状态。保留四种排序和本机记忆。
- 「整理旧链接」移入设置工具，位于文件名清理之后、查重之前。只在点击时读取预览，每批最多 10 个；先展示更新/暂停状态，明确确认后才提交原有带 revision 校验的接口。保留原模块、合集关系和手动维护暂停策略。
- 普通 ZIP 与限额内 ZIP64 均可上传首页；读取真实大小/偏移、ZIP64 目录和数据描述符，校验本地/中央记录、CRC、范围及重叠。仍限上传 25 MiB、单条目解压 32 MiB、总计 64 MiB、32 个条目；不执行脚本、不抓包内 URL、不重打包。
- 下载错误根据实际 signal/reason 与类型化错误区分超时、服务关闭、未知中止、连接中断；保留原始 cause，但界面/状态仅显示中文摘要。20 秒总下载预算和 6 小时周期不变。已有旧模块时才附加保留旧版本说明，首次导入不虚报。历史英文中止提示只映射显示，不改写历史数据库。
- 没有数据库结构、挂载、端口、地址检查、TLS、模块/合集/分享 ID 变更。

- 完整自动化回归：Node 25.9.0 与 Node 24.22.3 均 239/239 通过，0 跳过。新增 18 项测试覆盖 ZIP64、异常字段/偏移/描述符、原字节替换与恢复、中文错误分类/保旧、工具入口与预览确认。NAS Node 24.21.0 的同轮中止原因差异已通过显式记录首次中止修正；同步异常清理监听器。
- 用户提供的 ShortDrama、WesternStyle、yellowdrama 1.1.0、国产四个真实首页包，均完成临时本地数据库中的上传、导出、format 8 备份恢复；逐字节一致。原文件没有修改，也未加入页面演示数据；零外部下载。
