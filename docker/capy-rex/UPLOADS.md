# Docker 3.0 上传与七天恢复

模块文件及上一版均为 SQLite BLOB，不会生成宿主机模块文件夹。

## 预览与确认

一批 1～45 个 .js，单文件最多 25 MiB，总共最多 50 MiB。仅静态读取元数据，不执行模块代码。代码内部 ID 优先、完整文件名次之；ID/文件名匹配不同模块或多个候选时，必须显式选择目标。预览一小时过期；确认时会复核文件哈希和目标修订，已变化则要求重新预览。

确认支持新增、替换或跳过。同一批同一目标只能处理一次；重复确认返回已完成结果，避免重复模块。替换保持数据库模块 ID、公开 widget ID、合集引用、备注、分组和排序。

上传结果逐文件保留在预览窗口，全部处理完后点击“完成”关闭；失败项目可重新检查，不会把已成功项目重复上传。

订阅/链接模块的替换必须选择：临时替换（后续仍跟随上游）或手动维护（自动同步不覆盖本地内容）。模块管理可恢复自动维护。

## 上一版

替换现有文件前保存上一版，最多一版、七天过期；再次替换会滚动覆盖更老版本。恢复时交换当前版与上一版，但不改变模块身份、合集引用、备注、分组、排序或当前维护模式。内容相同时不生成无意义的新上一版。

文件写入、元数据、上一版指针、确认结果在 Docker 的同一个 SQLite 短事务中发布。失败会回滚；确认操作使用模块锁和修订检查。恢复不存在、已过期或变化过的备份会拒绝。

设置中的 format 6 备份包含当前文件、未过期上一版、图标库和文件名记录，并兼容恢复旧 format 1–5。恢复 JSON 备份不会延长原七天有效期。加密 REXENC 模块按字节保存，不解析其内部元数据。单模块下载与改名见 [FILENAMES.md](FILENAMES.md)。
