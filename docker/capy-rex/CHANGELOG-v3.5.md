# 3.5.0-local.1 · 选择性移植

本次同时实现第一、第二批。保留我们 Docker 3.4 的单 SQLite 存储、数据卷、认证、地址策略与旧公开路径，不直接使用第三方整包。2026-11-21 已部署 NAS 并推送 Docker Hub `latest`，见 [VALIDATION.md](docs/docker/VALIDATION.md)。

## 操作入口

| 能力 | 入口及规则 |
| --- | --- |
| 单模块快捷分组 | 模块行「分组」标签；当前分组不重复列为目标 |
| 单模块加入合集 | 模块行「＋ 合集」；仅手动合集，已有不重复，追加末尾 |

## 合集页内的首页配置

保留四项底栏；合集顶部增加「模块合集 ｜ 首页配置」紧凑分段，按需读取独立列表。上传首页 ZIP 后显示名称、头像、栏目和项目数量，卡片直接导出 `.rex`，管理菜单提供确认后分享、保地址替换、重命名与删除。原字节存现有 SQLite，不展开导入模块、不执行内容、不联网读取内含地址。默认私有，分享前提示完整文件可能包含私人地址和参数。替换失败保留旧文件，所有修改检查版本冲突。

新增幂等 `home_configs` 表，不新增挂载或部署变量。无首页仍导出 format 7，有首页使用 format 8；恢复支持 1–8，校验与写入沿用整体事务，并保护现有分享身份。旧版不能恢复 format 8，完整边界见 [HOME-CONFIGS.md](HOME-CONFIGS.md)。

## 订阅与合集管理按钮

订阅源和合集卡片右上角的文本三个点，统一替换为与模块列表相同造型的双滑杆 SVG 图标。图标为 18px、使用主题次要文字色，默认透明背景；保留 44 × 44px 点击区域，按下时显示淡紫背景和主题色图标，键盘聚焦显示 2px 焦点框。按钮分别提供「订阅管理」「合集管理」名称及弹窗语义，图标本身不重复朗读。

位置、原菜单及操作回调保持不变，不改订阅同步、合集编辑、公开路径或数据。浅深色及 320/390/1280 CSS px 已检查。

## 恢复备份提速与状态反馈

设置 → 工具 → 恢复：先选择 JSON 文件并确认覆盖规则，再上传。浏览器直接发送原始 File，不再读取、解析后重新序列化整份备份；显示真实上传百分比，后续显示校验/写入模块数量，只有数据库提交完成才显示成功。上传阶段防误关弹窗；上传完成后可关闭，重新打开继续查询原任务。网络中断不自动重复上传；未创建成功的任务先检查后台再允许重新确认。

服务端使用有大小限制的非回溯 Base64 校验与原生解码，修复较大单模块可触发正则栈溢出的路径。模块、上一版和图标字节在发布事务前解码/校验一次并复用；身份、路径、来源冲突仍在事务内以最新数据重新检查。进度查询使用独立只读 WAL 连接，写入时不排在事务后面等待。

新增同库 `restore_jobs` 任务状态表；同任务编号重复提交不会重复执行，同时只运行一个恢复任务。最终成功记录与数据同事务提交；进程异常重启后，未提交数据回滚，未完成任务标记中断，不自动重放。原格式 1–7、原管理员接口、模块/合集 ID、slug、历史公开地址和整体回滚规则保持；另支持首页 format 8。恢复不发起上游下载。

仅恢复文件上传放宽到 512 MiB 和五分钟，单模块仍最多 25 MiB，其他请求体保持原限制。没有新增部署环境变量，不改变认证、内网策略或 TLS 校验。仍需在服务内存可承受范围内操作，反向代理可有更低限制；不是流式恢复或断点续传。操作、API 与限制见 [RESTORE.md](RESTORE.md)。

## 文件名清理入口合并

设置首页移除独立的「模块文件名」区域，在工具中按「自动分类规则、文件名清理、查找重复模块、备份、恢复、清除所有数据」排列。文件名清理使用相同灰色线性图标、标题/说明和右箭头；说明为「清理文件名中的 rex，避免导入 Rex 后出现『模块校验失败』的情况。」（界面使用直角引号）。长说明自然换行，不截断。

点击后弹窗显示「自动清理新模块文件名」开关和「扫描已有文件名」。开关沿用已保存配置、修改即保存，失败回退；读取失败可重试，未确认设置前不允许切换。扫描需手动触发，空结果或失败留在当前弹窗显示；有结果时切换到原改名预览，不叠加弹窗；关闭期间返回的扫描结果不再弹出。预览仍支持勾选、编辑建议名称、20 项分批保存和已完成项目不重复提交。

只调整管理界面和入口，不修改后端文件名算法、下载易读命名、模块身份或旧地址兼容逻辑。弹窗明确说明只针对文件名中的 rex，不修改代码或处理其他原因的校验失败。

## 文件名兜底标题与清理结果一致

新上传、单模块链接导入和合集订阅中，没有可用代码 title、订阅清单标题或自定义标题时，使用最终接受的对外文件名去掉 `.js` 作为默认标题，包括自动去除 rex、手动指定名称及重名后缀。关闭自动清理仍保留未清理的文件名和默认标题。

列表、模块信息与公开合集读取时统一使用该规则；已有记录中可识别为原始文件名的兜底标题，按当前对外文件名展示，无需批量重写数据库。代码 title、订阅清单标题、已锁定自定义标题及与文件名不同的已保存标题不做 rex 字符串清理。原始文件名、模块 ID、模块字节、合集关系和历史公开路径不变。

## 模块行紧凑标签布局

来源、分组、所属合集与「＋合集」放在模块信息区域的同一个标签流中，空间不足时自然换行，不给每类标签强制另起一行。订阅为浅蓝、上传为浅橙、链接为浅青，分组为浅紫，合集为浅绿，深色模式使用对应的高对比文字。没有加入合集时不显示空合集标签，仍可点击「＋合集」；没有分组时显示可操作的「分组：未分类」。右侧模块导入按钮简写为「导入」，保留 Rex 导入链接与原管理按钮。

来源类型通过现有订阅关联的只读聚合判断：有合集订阅关联的模块显示「订阅」，单模块链接显示「链接」，无远端来源的模块显示「上传」。同时关联两类来源时优先显示「订阅」；此标签表示维护来源，不追溯已经不存在的导入历史。不新增数据库字段或改动模块、合集、成员、排序和公开路径；顶部筛选不变。

## 分类的明确边界

设置页「自动分类规则」入口与「查找重复模块」共用工具行样式：灰色线性图标、标题及简短说明、右侧箭头。仅统一入口外观，不改变规则编辑、保存或执行行为。

关键词按逗号/换行等分隔，忽略大小写；任意关键词命中即匹配；规则从上到下，首条命中生效。匹配范围为标题、原始文件名、作者、当前活跃的订阅源名称。加密模块只使用已保存元数据，不解密或猜内部字段。

首次保存、从关闭重新开启时，将当时全部模块标记为已有，不自动扫历史。后台约每分钟查看新模块，每轮最多 200 个，等待其创建超过 20 秒以便订阅映射稳定。已有分组不移动；手动合集仅按规则明确选择追加，保留已有顺序和其他合集关系。自动全部合集不能作为规则追加目标。不会删模块、替换 ID、改公开地址或覆盖备注。

手动整理只扫描未分类模块，每次最多 2000 个。确认令牌绑定规则、模块和引用快照；期间有变化拒绝执行，避免陈旧预览提交。预览不改模块；保存规则可能创建基线，但不会改旧模块分组或合集。

## 重复链接导入

单模块链接识别后，发现同内容哈希、明文模块代码 ID 或完整原始文件名会列出候选。名称相同仅提示疑似，不推断内容相同。默认不写入，管理员明确选择新增、覆盖或取消。

覆盖保留原模块 ID、播放文件名、分组、备注、排序、分享名和合集引用，复用七天上一版恢复。不会把新 URL 偷换成原模块更新来源，也不会另建订阅。若原模块有来源，必须选择临时覆盖（下次同步可能还原上游）或手动维护。切换更新来源仍在原「编辑订阅」中单独确认。候选在预览后变化则要求重新识别。

已登记的相同订阅 URL 继续复用，保留暂停状态。合集内部沿用既有 URL/远端映射关系去重和身份保留，不把所有同名模块自动合并。订阅来源只要仍引用已删除模块，日后可能重新导入，忽略重复不等同永久屏蔽订阅。

## 同步与兼容性

六小时周期、失败保留旧文件、下架只标记全部不变。失败重试使用本地上次失败的活跃条目快照；需要发现上游新模块或下架时用普通同步。多来源引用同一模块时仍可能互相更新，覆盖时不静默转移来源。

规则和忽略记录纳入 format 7 可选增强字段，旧备份可读。恢复规则默认关闭、恢复模块加入基线，避免批量误改。设置备份不包含部署环境变量，不扩大内网权限。

仅管理首页 HTML 流式 gzip，不缓存公开模块/合集响应，不绕过每次 ETag 和资源存在性检查。集合条目继续使用完整下载 + 内容哈希，未移植需新增 `subscription_items.etag` 的条件同步，因此不引入第三方截图的漏列路径。
