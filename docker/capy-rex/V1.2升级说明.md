## 12 项变更

1. **开发者用户名**：2–40 个中文、拉丁字母、数字、短横线或下划线。新用户名执行 NFKC 和首尾空白清理，用大小写无关规范形式检查重名；旧用户名不批量重写。登录先匹配旧精确用户名，再匹配规范形式，保留已有账号。
2. **公开卡片**：Capy 和 Rex 都有简短、各自适用的导入说明。版本与作者采用空格分隔；复制地址、下载 JS 和安装入口同时保留。
3. **界面**：公开页、工作台及模块管理台的主按钮与安装区域改为中性浅色表面、细边框、紧凑圆角；保留焦点轮廓、移动端布局和触控高度。
4. **Rex 安装**：生成 `https://rexnow.tv/widget/?url=` 加一次 `encodeURIComponent(公开JS地址)`。官网安装页已只读访问确认。是否成功导入仍由 Rex 客户端决定。
5. **Rex 加密**：上传入口显示“所有Rex模块均需加密 否则不予通过审核”，链接 https://rexnow.tv/encrypt/ 。统一新投稿与发布流程校验官方三行 REXENC v2 格式：`v=2`、`mkv=rex-1`、`alg=A256GCM`、12 字节 IV、60 字节 KB 和超过 16 字节的密文。只解析封装，不解密、不执行，不能据此证明密文来源或可运行性。已有公开明文 Rex 保持原字节。
6. **Capy 地址**：目录和安装入口从实际模块 ID 生成原始 JS 地址，base64url 编码无填充；管理台按平台导入。所报 UUID `68ba435e-f11d-...` 实测返回 404 JSON；实际 ID 是 `68ba435e-1f1d-...`。正确地址返回 200 JavaScript 并通过静态语法检查。Windows 点击 Capy 安装时提供复制 JS 地址，未注册任何 Windows 协议处理器；剪贴板不可用时显示可手动复制的地址。
7. **作者分组 / 播放器分类**：两个独立字段。新发布按审核快照中的作者分组发布，同名作者跨 Rex/Capy 共用分组；管理台可以独立修改播放器。没有重新解释、重命名或搬动现有用户分组。维护已有组件时请核对作者分组，这是明确的发布选择。
8. **管理员上传**：模块管理台“上传”进入统一工作台；选择新增或维护、维护目标、JS 文件、标题、作者分组、播放器、版本和更新说明，然后“检查并预览”，确认后直接发布。更改表单会使预览确认按钮失效，需要重新检查。批量 ZIP、订阅和旧管理 API 仍作为原有维护工具保留；新的人工投稿与逐个上传请使用统一入口。
9. **规则**：原有作者分组关键词规则保持兼容；工作台新增独立播放器建议规则，支持 filename、category、code。按配置顺序检查，命中多个不同播放器返回 unknown；建议不覆盖手工选择或现有分类。正则仅支持字面量、字符类、锚点及一个 `{n,m}`（最大 32），拒绝分组、交替、无限量词、回溯引用、环视等，规则最长 160 字符，输入最多 4096 字符，最多 50 条。示例：`[{"field":"filename","pattern":"^capy[-_]","platform":"capy"}]`。代码接口启发式仅供建议，共享 API 或冲突会得到 unknown；不存在通用的加密平台识别方式，只有有效 Rex 专有封装可以明确建议 Rex。
10. **开发者投稿**：明确区分新增和维护已有组件；使用同一元数据预览。来源字节、文件名、标题、分组、播放器、版本、更新说明存入不可修改快照。审批校验源码 SHA-256、所有权、平台和原公开版本指纹（包含作者分组及说明）；同一 SQLite 事务发布文件指针、全部元数据、归属和审核状态。审核失败整体回滚，公开旧版本保留。
11. **测试与检查**：上传页链接 https://modules.rexnow.app/ 。官网公开实现使用浏览器 Worker 和 Widget 环境模拟；本项目没有声称复刻它。Capy 官方文档是 App 沙箱契约，本次未发现并验证可直接复用的官方在线等价测试器。复用 MIT 开源 Acorn 8.15.0，提供独立 Docker **静态**检查器，见下文。没有动态执行上传代码。
12. **管理员账号**：登录后在账号区域输入新用户名、当前密码和 8–256 字符新密码；当前密码复核成功后同时更新并撤销全部管理员会话。未设置新用户名的旧安装继续支持原密码单字段登录；一旦设置用户名，登录必须填写该用户名。原管理台修改密码入口跳转工作台，旧 NAS 密码更新 API 不再绕过当前密码复核。无生产密码重置、无新增生产测试账号。

## 静态 Docker 检查器

在项目目录执行：

```sh
docker build -f validator/Dockerfile -t capy-rex-validator:V1.2 .
sh validator/check.sh < /path/to/module.js
```

输入只通过 stdin。运行配置为非 root、无网络、只读根文件系统、无主机目录挂载、无 Docker socket、禁用 capabilities、no-new-privileges、32 PID、160 MiB 内存和交换上限、0.5 CPU、64 文件描述符、外层 10 秒超时及 2 秒强制终止等待。内部 Node 堆上限 96 MiB，输入上限 2 MiB。Web 上传静态解析不调用 Docker daemon。

检查 JavaScript 语法、可静态读取的元数据、WidgetMetadata 声明和 Rex 封装。输出 `mode: static-only`。不会运行网络请求、测试真实列表/详情、解密密文、验证业务结果或保证 App 兼容性。`while(true)`、`process.exit()` 都只作为语法解析；真实测试已确认不会执行它们。

现有库预检选用 Acorn，无额外付费服务。源码保存在 `nas/vendor/acorn.mjs`，MIT 许可证在同目录，版本 8.15.0，来源 npm 官方 registry。
