# 单模块下载与文件名清理

以下为 3.2.1 文件名功能说明，已保留在 Docker 3.3.0-local.1。3.3 另增独立的分享别名：显式确认后复制／合集成员优先使用固定分享名；下载仍使用可读标题及实际版本，原始名称与有效文件名仍保留。本版备份为 format 7，兼容旧 format 1–6；下文 format 6 和 pre-v32 均为历史版本说明。见 [CF-3.3-DOCKER.md](docs/docker/CF-3.3-DOCKER.md)。未部署或推送镜像，未验证播放器。

## 3.2.1 下载名称补丁

仅调整「下载模块」返回的附件名称：使用模块当前显示标题，有实际版本时追加 `-v版本`，如 `Javheo-v1.3.2.js`。自定义标题、代码标题、订阅清单标题遵循现有显示优先级；加密模块使用已有清单信息，不读取加密内容。无标题时回退到已保存的文件名，无实际版本时省略版本；标题末尾已带相同版本时合并。延续文件名安全字符和 rex 清理规则。下载名称即时生成，不写入数据库，不影响合集内文件名、URL 或更新匹配；无需扫描或新增设置。文件内容保持原始字节。此补丁不增加迁移或备份字段。

## 使用

- 模块「更多操作 → 下载模块」下载当前数据库字节；全部列表和分组列表都可用。登录失效、模块不存在或文件缺失会显示错误，不会把错误 JSON 保存成脚本。
- 上传预览同时显示原始文件名和可编辑的导入后名称。替换目标切换时保留目标已确认的名称。提交时校验文件和目标版本，同名自动附加编号，结果显示实际名称。
- 链接导入显示从 URL 解码提取的名称和建议，可编辑；合集内模块使用相同规则。下载内容识别为合集时忽略单模块名称输入。
- 设置 → 模块文件名的自动清理默认开启；关闭后仅影响新模块，不撤销已有名称。
- 扫描已有模块只列出当前对外文件名仍含 rex 的模块，可勾选、编辑和分批确认（每批最多 20 个）。扫描后模块发生变化会拒绝该批，需重新扫描；此前成功批次保留。

## 规则与兼容

只从文件名主体删除不区分大小写的字面 `rex`，如 `REX__视频-rex.js → 视频.js`；清理多余分隔符，保留 `.js`。空名称生成 `module-<模块编号>.js`，不同模块同名时附加模块编号。文件名禁止路径、控制字符及常见文件系统特殊字符，主体最长 150 字。

`modules.filename` 和历史原始名称继续用于上传匹配，不以清理后的名称推断两个模块相同。对外文件名独立保存到 SQLite `module_names` 表。模块内容、WidgetMetadata、标题、模块 ID、合集 ID、合集路径、成员顺序、备注不因改名改变。订阅刷新和文件替换保留已确认名称；历史原始上传名仍可匹配。

新命名后的合集成员使用 `/api/modules/<id>/file/<编码文件名>.js`，响应头也包含 UTF-8 文件名；复制链接和导入 Rex 按钮使用该固定名称。「下载模块」使用上文的标题及当前版本名称。原 `/api/modules/<id>.js`、`/raw`、裸 UUID 路由和旧的命名路由仍按模块 ID 提供当前内容。已有合集订阅地址不变；设备需要重新获取合集后才能看到新的成员文件链接。未验证具体播放器对文件名或缓存的行为。

未触发改名的旧模块保持原成员 URL。升级启动只建表，不扫描改名；已有模块需管理员确认。重传和旧备份恢复不会偷偷清理旧名称。

## 备份与回退

从 3.1 升级首次启动前，原 SQLite 在 `data/backups/pre-v32-<摘要>.sqlite` 保存一致性完整快照，再事务增表；不创建新数据卷。新导出 format 6 包含对外名称、原始名称历史和自动清理配置；兼容读取 format 1–5。较旧 JSON 无名称数据时，已有已确认名称保留，新恢复模块保持原名。3.1 及更旧应用拒绝 format 6。

若之后部署本版又要回退：停止服务，使用当前版本 `restore-snapshot.js <实际 pre-v32 快照> --offline` 恢复升级前数据库，再换回 3.1 代码/镜像。回退会返回快照时间的状态，工具会保存升级后的数据库供恢复。不要清空数据卷。已发布的命名模块链接需要本版路由；不能在使用新名称后只换旧镜像。
