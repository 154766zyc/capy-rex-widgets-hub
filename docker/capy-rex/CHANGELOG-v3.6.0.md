# 3.6.0 更新说明（2026-11-24）

## 重点

- **用量大降**：定时维护一次从约 5,035 行降到约 35 行（1000 个模块），一天从约 145 万行降到约 1 万行；你的站原来一次 18,099 行，预计降到几十行。
- **不再超免费额度**：维护一天只用 500 万行额度的约 0.2%～0.3%（3000 个模块以内）。
- **没改数据就不读数据库**：Rex 再拉合集、管理页再开列表都从内存回，0 次查询。
- **新设置「自动更新」**：6 / 12 / 18 / 24 小时可选，默认 6 小时。
- **升级最简单**：覆盖 `index.js` 再 `deploy`，`wrangler.toml` 不用改，数据保留。
- **可选边缘缓存**：默认关，要打开才改 `wrangler.toml`；没在真实 Cloudflare 上测过。
- **支持 Rex 1.2 HTML 首页卡片**：首页包 version 2、`rex-html/`、内联 `htmlTemplate` 都能上传。
- **「检查首页」**：卡片、尺寸声明、缺字段、本机模块、外站链接一次看清；卡片上直接显示摘要。
- **首页工具**：「换成 Hub 模块链接」「装上 HTML 卡片」「取消分享 / 换新分享链接」。

## 基本信息

- 以 3.5.8 为底，只出 Cloudflare 版。
- 合并了两条线：省 Cloudflare 用量 + HTML 首页卡片（原 3.5.9 HTML 卡片版）。
- 数据库自动补 3 个索引，首页配置表自动加 3 个栏位（检查结果缓存），其它结构不变。
- 3.5.8 和 3.5.9（HTML 卡片版）都可以直接覆盖升级。
- 模块、合集、首页的 ID、分享名、公开地址都不变。
- 直接覆盖部署，数据保留；`wrangler.toml` 的 `name` 不要改。
- `wrangler.toml` 可以继续用自己那份；每 5 分钟的 Cron 不用改。

## 为什么要改

- 3.5.8 每 5 分钟的定时维护，会把模块表、KV 表整表扫描好几遍。
- 实际站点一次维护读约 18,099 行。
- 一天约 520 万行，超过免费计划每天 500 万行。
- 别人部署后很快就收到用量警告。

## 省了多少（本地模拟实测，按 EXPLAIN 估算）

- **定时维护一次**（1000 个模块）：约 5,035 行 → 约 35 行。
- **定时维护一次**（3000 个模块）：约 47 行。
- **一天的定时维护**（288 次，1000 个模块）：约 145 万行 → 约 1 万行。
- **一天的定时维护**（3000 个模块）：约 1.4 万行。
- **闹钟空闲间隔**：最长 15 分钟 → 最长 1 小时。
- **Rex 再拉没改过的合集**（含 304）：约 402 行 → 0 行（内存）。
- **Rex 第一次拉合集 / 改过数据后**：不变，约 2 × 合集模块数 行。
- **管理页再打开模块列表**（没改数据）：约 2 × 模块数 行 → 只读几行登录信息。
- **图标、favicon、manifest、CORS 预检**：不再进 Durable Object。
- 部署后可在 Cloudflare 网页 → Durable Objects → 指标 看实际「读取行数」。

## 改了什么

### 定时维护走索引

- 标题补扫：只查还没扫的模块；扫完后每次读 0 行。
- 链接模块自动刷新：只读到点的单链接模块。
- 过期 KV 清理：用 `expires_at` 部分索引。
- 自动分类：没有新模块就跳过；最多 24 小时补扫一次。
- 图标清理：没有到期图标源时，最多 6 小时一次。

### 没改数据就从内存回

- 公开合集（`.rex` / `.fwd` / JSON）。
- 管理页模块、合集、分组三张列表。
- 304 和 HEAD 也从内存回。
- 管理列表必须登录才能拿到。
- 缓存上限 64 条、16 MB。
- Durable Object 被回收后，第一次请求照常读数据库。

### 只有真的改了数据才算写入

- 维护里的清理大多删 0 行，以前也算写入，内存缓存每 5 分钟被清空一次。
- 现在看实际改动行数（`changes()`）。
- 建表、建索引一律算写入。

### 少写闹钟

- 每次 `setAlarm` 算 1 行写入。
- Cron 每 5 分钟调一次：已有更早的闹钟就不重设。
- 空闲时闹钟最长睡 1 小时。
- 闹钟响过后一定重设。

### 存储清理

- 以前：每一列各扫一遍整张表（`modules` 有几十列）。
- 现在：每张表只扫一遍。
- 没删东西时不算写入。

### 静态文件不进 Durable Object

- PWA 图标、favicon、manifest、CORS 预检直接在 Worker 里回。

### 自动更新间隔可选

- 位置：设置 →「自动更新」。
- 可选：6 / 12 / 18 / 24 小时，默认 6 小时。
- 对合集订阅和链接模块都有效。
- 改了以后按「上次完成时间 + 新间隔」重排下一次同步。
- 手动「同步」「全部同步」不受影响。
- 接口：`GET / PUT /api/admin/sync-interval`。

### 可选：边缘缓存（默认关闭）

- 打开后，Rex 拉合集和下载模块由 Workers Cache 直接回。
- 命中时不进 Durable Object：不算 DO 请求、不读数据库行。
- 仍算一次 Worker 请求。
- 合集最多晚约 1 分钟、模块最多晚约 5 分钟更新。
- 管理页、登录等带 Cookie 的请求永远不进缓存。
- 进缓存的请求会去掉 Cookie 和 Authorization。
- 配置不对时自动回退到 Durable Object。
- 打开方法见 `wrangler.toml` 末尾和 `CF-DEPLOY.md` 第 17 节。
- 没在真实 Cloudflare 帐号上测过。

## HTML 首页卡片（适配 Rex 1.2）

- **首页包 version 1 和 2 都收**：
  - 认得 `rex-html/` 里的 HTML 卡片文件（布局用 `htmlTemplate: "文件名.html"` 引用）。
  - 认得 Rex 1.2 备份里的写法：整段 HTML 写在 `htmlTemplate` 里，带 `htmlTemplateSource`。
  - 认得 `rex-scripts/` 内置脚本。
- **包内文件数**：32 → 256。
- **直接拒绝**：布局引用了不存在的 HTML 文件、`htmlTemplate` 为空或文件名不安全（如 `../x.html`）。
- **新样式 `portraitImage`**：照常通过（实际备份里有）。

## 检查首页

- **位置**：首页卡片调整按钮 →「检查首页」；只读，不执行脚本、不联网。
- **卡片摘要**：首页卡片标题下直接显示，例如「v2 · 2 张 HTML 卡片 · 1 个内置脚本 · 2 条提示」；有提示变橙色。
- **HTML 卡片**：来源（文件 / 内联）、模板 ID 和版本、几行共用、字节数、尺寸声明。
- **会提示的问题**：
  - 超过 32,768 字节。
  - 缺少或重复 `rex-widget` 声明；尺寸写错（card x1～x4、full-width 96～960、rail 比例 1:3～3:1、background 只能 glass / clear-glass）。
  - 引用外部脚本、样式、图片；含网络请求代码。
  - `style` / `gridSize` 和声明对不上。
  - 布局项目缺 13 个必需字段。
  - `file:///x.js` 找不到；用 `file://UUID.js` 本机模块（别人导入后是空行）。
  - `rex-html/`、`rex-scripts/` 里没被引用的文件。
- **模块对照**：每个模块是本站链接、外站链接、本机模块、内置脚本还是 Rex 内置；本站有没有、能不能换。
- **复制全文**：报告可一键复制。
- **结果缓存**：按文件指纹保存，同一个文件不重复解压。

## 首页工具

- **换成 Hub 模块链接**：本机模块（`file://UUID.js`）和内置脚本换成本站同 widgetId 模块的链接；可逐个勾选；本站没有的不动并列出。
- **装上 HTML 卡片**：选一个项目，上传官方工作台下载的单卡 `.html`；自动放进 `rex-html/`、配好 `style` / `gridSize`、manifest 改成 2；也可以去掉卡片。
- **两种保存**：另存为新首页（默认），或覆盖当前首页（保留 ID 和分享链接）。
- **取消分享**：旧链接马上失效，首页保留。
- **换新分享链接**：旧链接作废，新链接自动复制（iPhone 也能用）。

## 其它修正

- 升级上来的站补不上新索引（旧站已有建表标记）：改用单独标记，第一次打开就补上。测试中发现。
- 新索引让标题补扫改走整表扫描：`ORDER BY` 改成和索引一致。
- 检查里的标签扫描改成线性切分：10 MB 恶意 HTML 检查从约 1.7 秒降到约 70 毫秒。
- HTML 只检查前 128 KiB、脚本只扫前 512 KiB；字节数仍按完整文件算。
- 大请求体只给上传首页、替换文件、装 HTML 卡片（26 MiB）；分享、换链接等只收 32 KiB。
- 检查报告的「取消」按钮在 Chrome 上没隐藏：已修。
- 版本号只在 `package.json` / `CF_VERSION` 写一次，测试从这里读。

## CF 的限制

- **DO 读取**：免费每天 500 万行。
  - 3.6.0 定时维护一天约 1～1.5 万行（3000 个模块以内）。
  - 主要用量变成 Rex 拉合集、管理页打开模块列表（DO 被回收或改过数据后的第一次）。
- **DO 写入**：免费每天 10 万行；`setAlarm`、删除都算写入。
- **Worker 请求**：免费每天 10 万次；边缘缓存命中也算。
- **内存缓存**：只在 DO 没被回收时有效；改了任何数据就失效。
- **单次上传**：最多 100 MB；超过请分开导出（模块数据 / 首页 / 文件）。
- **内存 128 MB**：
  - 模块文件边读边处理。
  - 首页配置和文件栏目仍整段读进内存。
- **存储**：每个 Hub 1 GB（付费 10 GB）。
- **文件栏目**：单个 25 MiB，总共 100 MiB、200 个；只收 PDF、txt、zip。
- **首页包**：单个最多 25 MiB。
- **图标**：单张 2 MiB，缓存总共 128 MiB。
- **定时任务**：每 5 分钟一次；订阅和链接模块按设置的间隔检查（默认 6 小时）。
- **订阅地址**：只能用公网地址。
- **首页检查是静态的**：不代表 Rex 原生渲染、导入或播放已通过；加密脚本看不到里面的地址。
- **HTML 卡片**：单张最多 32,768 字节；检查、换链接、装卡片都要把整个首页包读进内存。
- **换成 Hub 模块链接**：只按 widgetId 匹配，不比代码；链接用打开管理页时的网址，换域名后旧首页不会跟着变。
- **生成的新首页包**：不压缩，体积比原包大；超过 25 MiB 拒绝。
- **首页**：Rex 新版已支持用链接导入首页，Hub 还没接上。
