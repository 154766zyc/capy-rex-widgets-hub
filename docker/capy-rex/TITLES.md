# Docker 3.0 标题处理

静态扫描 WidgetMetadata 的顶层字符串字面量，最多 256 KiB；忽略动态表达式、方法和嵌套对象，不执行任何模块代码。REXENC 加密内容不参与解析。

标题优先级：手动锁定名称 → 代码 title → 合集清单 title → 已保存名称 → 文件名兜底。版本、作者和内部 ID 也只取静态元数据。新上传的 ID/文件名匹配与已有公开 widget ID 是不同概念：替换文件不会更换已有公开身份。

为了无痛升级，旧 Docker 模块的已有显示名称初始锁定，避免新解析器改变现有合集显示。可在模块管理里关闭标题锁定；之后按上述优先级随上游更新。新模块使用最新解析规则。后台补扫每次最多两个历史记录，不改变文件字节。
