# 多图标源与合集图标

## 使用

设置 → 图标集 → 添加图标源。支持如下格式，不执行 JSON 中的代码：

```json
{"name":"Rex_Logo","icons":[{"name":"Purple","url":"https://example.com/purple.png"}]}
```

最多 20 个图标源，每源最多 2000 个不同图片 URL。名称是展示信息，不作为身份；同源相同 URL 去重，不同源的同名图标各自保留，图片字节相同时只存一份。源名称可编辑；链接修改请新建来源。图标清单与模块订阅独立，不会进入模块库。

每天检查清单，也支持“刷新”。使用 ETag/Last-Modified 条件请求；失败退避 5 分钟起、最多一天，保留上次成功清单和错误原因。停用后不再自动同步或进入选择器；移除后删来源/条目，但不删合集已引用的图片。

## 选择

新建/编辑合集 → 选择图标。多个来源时显示“全部图标集”和各来源，单来源省略下拉框。支持名称搜索、中文常见颜色搜索、每页 12 项分页、候选选中和较大预览。手机三列，桌面四列。深浅底板只影响预览，不改变图片内容。

点击图标仅选择候选；“使用此图标”填入草稿；“保存合集”才持久化。取消选图保留表单，取消编辑不改数据库中的合集。清除只清草稿，保存后才清空合集 icon。保持原路径时，旧版非英文字母/数字的历史路径仍可原样保存。

保留手填 HTTP(S) 图片 URL，提供“预览地址”。预览是浏览器直接加载，后端保存时仍会独立验证并下载；二者网络可能不同。新图片缓存失败时拒绝保存，保留原合集及草稿。旧远程图标没有变化时不下载、不改写它；这也适用于只改标题/描述的操作。

## 数据与稳定性

`icon_sources` 保存配置与同步状态；`icon_entries` 保存清单与浏览缓存引用；`icon_assets` 的 BLOB 保存图片原始字节。图片地址为 `/api/icons/<SHA-256>.png|jpg|webp`，公开合集自动输出基于原 PUBLIC_URL 的绝对地址。无需图片目录、挂载或新增 npm 依赖。

图标清单同步后，浏览缓存可重新下载；已经保存的合集仍引用旧的内容哈希。重新选图并保存才换版本。编辑表单选中的是当时已预览的固定缓存地址，期间源刷新不会偷换成另一版图片。客户端有缓存时需刷新合集。

图片按当前页按需下载，前后端均限制并发，后端最多 3 个同时下载。总缓存 128 MiB、单图 2 MiB、清单 1 MiB、下载 20 秒、最多 5 次重定向。仅接受 PNG、JPEG、WebP 文件结构和匹配 MIME，最多 8192×8192 且不超过 1600 万像素，拒绝 SVG、HTML、JS。

已被合集引用的资源不会自动清除。未引用缓存 30 天后可回收；达到总额度时优先回收未引用资源，仍不足时拒绝新增图片而不是删已用图标。选择和缓存不会自动改变任何合集。

复用 SOURCE_ADDRESS_CHECK / TRUSTED_SOURCE_ORIGINS，TLS 验证不关闭；清单中每项和重定向逐个校验。后台接口只允许登录管理员；公共图片接口只读已存在的哈希资源，不能代理任意 URL。不发送管理凭据给上游。

## 备份和升级

图标功能自 format 5 起加入备份，当前 3.3 导出为 format 7，兼容恢复 format 1–6。包含三张图标表以及 base64 图片，恢复会验证类型、摘要、来源身份、合集引用及额度，任何错误在发布前中止。旧应用不能恢复 format 7。JSON 恢复请求上限 512 MiB，超大库请停机做完整 SQLite 备份。

从 3.0.x 第一次升级先保存 pre-v31 一致性快照，再在原库事务增表；保留原 .env、原卷、项目名、PUBLIC_URL 和端口。需要回滚时同时恢复匹配的镜像与数据库，详见 UPGRADE.md。

## 接口

- `GET/POST /api/admin/icon-sources`：列出 / 添加并首次同步。
- `PATCH/DELETE /api/admin/icon-sources/:id`：编辑名称/启用状态 / 移除来源。
- `POST /api/admin/icon-sources/:id/refresh`：刷新；`synced:false` 表示失败并保留旧清单。
- `GET /api/admin/icons?source=&q=&page=1`：启用源的分页检索。
- `POST /api/admin/icons/:entryId/cache`：按需缓存，返回固定图片路径。
- 合集原 POST/PATCH：省略 icon 字段表示不改；`icon_url:""` 或 `icon_entry_id:null` 清除；`icon_url` 支持外部地址或已有本地图片路径；`icon_entry_id` 选择当时最新可用条目。不能同时提交两种非空来源。
- `GET/HEAD /api/icons/:hash.:ext`：公开只读图片，支持 ETag / 304 和长期不可变缓存。

本发行包尚未部署到 NAS，不包含任何真实数据库、管理员密码或登录会话。
