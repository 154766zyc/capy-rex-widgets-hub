# Capy/Rex Widgets Hub V1.4 中文部署指南

1. 解压 ZIP，进入 `compose.yaml` 所在目录。
2. 复制 `.env.example` 为 `.env`，按实际环境设置端口、首次初始化地址和公开域名。
3. 创建 `data/` 并只授予服务运行账号所需权限。
4. 执行 `docker compose config --quiet`、`docker compose up -d --build`、`docker compose ps`。
5. 首次访问初始化页面创建管理员密码，用 `/healthz` 检查服务。

默认示例端口为 8080，Compose 使用 host 网络。更改端口时同步修改反向代理和健康检查地址。

更新前先做 SQLite 一致性备份，保留 `.env` 与 `data/`，替换程序后重建容器。不要运行 `docker compose down -v`，不要删除已有数据库来排障。

公开发布不得包含真实 `.env`、数据库、WAL/SHM、备份、账号或密码。
