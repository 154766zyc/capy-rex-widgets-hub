# 首页配置管理

## 界面与使用

底栏保留「订阅 · 模块 · 合集 · 设置」。进入「合集」，通过顶部紧凑切换条选择「模块合集 ｜ 首页配置」，各自列表和操作互不影响，并记住本机上次选择。

- 模块合集保留原列表及「＋ 新建合集」。
- 首页配置显示「＋ 上传首页」；卡片显示名称、头像、栏目/布局项目数量、文件大小和更新时间，直接提供「导出 .rex」。
- 卡片管理菜单提供「复制分享链接、替换文件、重命名、删除首页配置」。
- 上传需要手动选择文件并确认；相同原文件重复上传会提示使用原卡片。最多保存 200 个配置，单文件最多 25 MiB。

支持从 Rex 导出的 `video.fika.rex.home-package` ZIP 包，version 1 和 version 2（3.6.0 起），根目录包含 `rex-manifest.json`、`rex-home.json`、`rex-layout.json`。version 2 还可以带 `rex-html/`（HTML 首页卡片，布局项目用 `htmlTemplate` 写文件名）和 `rex-scripts/`（内置脚本）；Rex 1.2 那种把整段 HTML 直接写在 `htmlTemplate` 里的写法也接受。这不同于模块订阅合集 JSON；上传首页包不会导入里面引用的模块、执行脚本或下载 URL。其他格式不猜测转换。

## 首页检查（3.6.0）

首页卡片菜单的「检查首页」读取保存的原文件，生成只读报告，不执行脚本、不联网：

- 格式版本；含 HTML 卡片却还是 version 1 时提示改成 2。
- 每张 HTML 卡片：来源（`rex-html/` 文件或内联）、模板 ID（`htmlTemplateSource`）、字节数、尺寸声明，以及问题——超过 32,768 字节、缺少或重复 `rex-widget` 声明、尺寸写错（card 只能 x1～x4，full-width 96～960，rail 比例 1:3～3:1，background 只能 glass / clear-glass）、外部脚本/样式/图片、网络请求代码、`style` / `gridSize` 和声明对不上。
- 布局项目缺少 13 个必需字段中的任何一个；`file:///x.js` 在 `rex-scripts/` 里找不到；用 `file://UUID.js` 本机模块（别人导入后为空）；`rex-html/`、`rex-scripts/` 里没被引用的文件。
- 内置脚本：加密（`REXENC`）或明文、大小、明文脚本里出现的域名；模块链接按域名统计。
- 固定说明：首页包本来就不包含 Worker 或接口服务。

只有「布局引用的 `rex-html/` 文件不在包里」或 `htmlTemplate` 文件名不安全会拒绝上传，其余只提示。上传和替换成功时也会返回摘要（卡片数、有问题的卡片数、内置脚本数、提示数）。检查是静态的，不代表 Rex 原生渲染、导入或播放已通过。

## 首页工具（3.6.0）

- **卡片摘要**：列表直接显示格式版本、HTML 卡片数、内置脚本数、本机模块项目数和提示数。结果按文件指纹（`checked_hash`）缓存在 `check_json` / `check_summary` 里；文件换了或检查规则版本（`CHECK_VERSION`）变了才重算。重算写回缓存但不改 revision。
- **模块对照**：报告里按 widgetId 和本站模块库比对，标出本站链接 / 外站链接 / 本机模块 / 内置脚本 / Rex 内置，本站有没有、版本、是否加密、能否换成本站链接。
- **换成 Hub 模块链接**：`POST /api/admin/home-configs/<id>/relink`，`{revision, widget_ids?, save?}`。只换 `file://` 本机模块和 `file:///` 内置脚本，按 widgetId 匹配本站模块（同 ID 多个时取最近更新的）；没人再用的 `rex-scripts/` 文件删掉。
- **装上 HTML 卡片**：`POST /api/admin/home-configs/<id>/html`（multipart：`revision`、`section`、`item`、`file` 或 `remove=true`、`save`）。按尺寸声明配 `style` / `gridSize`，manifest 改 2；全宽 / 横滑要求该行只有一个项目，同一行 HTML 方卡档位要一致。
- **保存方式**：`save=new`（默认）另存为新首页，名字后加「（Hub 链接）」「（HTML 卡片）」；`save=replace` 覆盖当前首页，保留 ID 和分享链接。新包是 Mac Rex 顺序（manifest → layout → home）的不压缩 ZIP，JSON 为紧凑格式、`/` 写成 `\/`。
- **取消分享 / 换新链接**：`POST …/share/revoke`、`POST …/share/rotate`，都要带 `revision`。取消后旧地址立即 404；换新后旧地址 404、新地址可下载。

## 原文件、名称与替换

原始 `.rex` 字节完整保存在现有 `rex.sqlite`，导出不重新打包。显示名称默认读取包内标题，缺失时回退到上传文件名；导出名称使用易读的「显示名称.rex」。重命名只影响 Hub 卡片与下载名称，不修改包内首页名称或文件内容。

替换前校验新文件，成功后保留本地 ID、显示名称和已经启用的分享地址，更新包内信息与原文件；失败保留旧文件。编辑使用版本号检查，旧窗口提交会被拒绝，刷新后再操作。删除只删除该首页配置及其分享入口，不删模块库或模块合集。

## 分享边界

默认只有管理员可查看和导出。首次「复制分享链接」需确认公开完整原文件：其中可能包含模块地址、接口参数或其他私人信息，请先自行检查。

确认后生成不透明随机地址 `/api/home-configs/<随机标识>.rex`，持有该链接的人无需登录即可下载；不要把随机地址当作独立的访问密码。替换文件沿用地址，删除后地址失效。3.6.0 起可在调整按钮里「取消分享」或「换新分享链接」。

分享是 HTTPS/HTTP 文件下载，不冒用 `rex://widget` 模块协议，不承诺播放器一键导入。需下载后按 Rex 客户端支持的方式导入；未进行真机播放器验证。下载响应禁止缓存，但已经被他人下载的副本无法收回。

## 校验和部署

ZIP 在内存中按限制读取，核对目录、长度及 CRC，不落地解压。支持普通 ZIP 和限额内 ZIP64（含扩展大小、偏移和目录记录），ZIP64 不提高容量限制。拒绝缺损/越界扩展字段、路径穿越、重名、重叠、加密、链接、多卷及不支持的压缩方式；最多 256 个条目（3.6.0 起，原来 32 个）、单条目解压后 32 MiB、总计 64 MiB。只读取 JSON 元数据，3.6.0 起「检查首页」还会读 `rex-html/` 和 `rex-scripts/` 的文本做静态检查；头像只接受通过校验的 PNG/JPEG/WebP，异常头像使用占位。

启动幂等增加 `home_configs` 表，与既有数据共用 SQLite 和原挂载，不新增环境变量。模块/合集 ID、原公开地址和网络下载策略不变。首页上传限时 120 秒，反向代理仍可能设置更低大小或超时限制。

## 整库备份恢复

- 没有首页配置时继续导出 format 7；有首页配置时使用 format 8，包含全部原文件、摘要、显示名称及分享身份。
- 本版读取 format 1–8；format 8 必须包含首页列表。老 Docker/CF 版本不能直接恢复 format 8，请使用明确支持它的版本，不能手改格式编号。
- 首页和其他数据在同一事务恢复；坏文件、摘要错误、分享身份或地址占用冲突会拒绝恢复，不留下半份数据。
- 恢复旧备份不删除本地额外首页；旧私有备份不会撤掉本地已启用分享。相同 ID 已有另一分享身份时拒绝覆盖，避免使已有地址失效。
- 「清除所有数据」包含首页配置，确认后其分享地址也失效。
