# 3.5.3（2026-11-22，优化版）

以 3.5.2 为底的优化版，**不是上游发布的 3.5.3**。数据库结构、模块/合集/首页 ID、分享名、公开地址、备份格式（format 1–8）都不变，可直接覆盖 3.5.2 部署。

## 优化

- **公开下载少查 SQL**：每次下载 7 条 SQL（含 2 次全表扫描）→ 3 条、0 次全表扫描。新增 `decorateNameOne` 只查单行；下载改用行里已有的 `file_key`。
- **`DOKV.getWithMetadata` 3 条 SQL → 1 条 JOIN**：一次拿全 value + metadata + expires_at，过期语义不变。
- **备份导出、恢复少做重复查询**：导出每模块省一次 `file_key` 查询；恢复循环 `find` O(n²) → O(1) 查表；恢复时上一版 `kv_key` 查询 + 删除从 2N 条并成 2 条。
- **`title_scan_v1` 加索引**：cron 每轮的标题扫描走覆盖索引；schema 标记 v1 → v2，旧库重跑一次即可拿到索引。
