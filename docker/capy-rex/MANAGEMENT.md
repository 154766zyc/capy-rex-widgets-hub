# Docker 3.1 批量管理与我的合集

此文档对应本 Docker 包；不包含 Cloudflare 正式站点部署操作。

## 模块库

点击“选择”进入批量模式，可搜索、按分组筛选、全选当前列表、清空选择。批量移动分组和加入合集每请求最多 10 项，永久删除每请求最多 2 项。响应逐项报告成功和失败；失败项继续保持选择，网络中断未确认的项目可以安全重试。

加入合集只追加未存在的模块，不改变既有成员的顺序。删除模块会先原子移除记录和所有合集引用，再清理数据库中的文件字节、指针和上一版。不存在的模块不可通过孤儿文件键继续下载。

## 我的合集

管理模块窗口支持搜索、分组筛选、仅看已选、顺序移动和专用手柄拖动。取消不会保存。成员保存携带打开窗口时的有序基线；若另一个窗口修改过合集，会返回 409 并要求重新打开，不静默覆盖。

普通自选合集不会自动加入订阅新增模块。旧 Docker 的 autoAll 合集仍自动追加新模块，可在“编辑合集”关闭该选项，关闭不会移除已有成员。

旧合集路径可含旧版 Unicode、空格或连字符，编辑其他信息不要求改路径。修改为新路径时只接受字母数字，并永久保留旧路径作为别名；和其他合集或别名冲突会拒绝，而不是悄悄换地址。

新建/编辑合集提供“选择图标”：设置中添加多个图标源后，可按来源筛选、搜索名称/颜色、翻页、预览和选中。保留手填图片地址。选择、清除只改草稿，保存合集才生效；取消不会修改现有合集。图片存数据库并输出固定 Hub 地址，来源移除不影响已保存图标。规则见 [ICONS.md](ICONS.md)。

“导入 Rex”使用 rex://widget?url=，合集/模块 URL 只编码一次。网页只能发起打开，不会伪称客户端已经导入成功。
