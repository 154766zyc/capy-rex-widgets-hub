# Docker 3.3 订阅源

“链接”／“添加订阅”入口先点击「识别链接」，核对类型、标题及文件名后确认。单 JS、REXENC 加密模块和包含 widgets 列表的合集均保存为正式订阅源，每六小时开始一轮；“立即同步”可手动触发。预览仅缓存文件，不创建模块或订阅，十分钟内确认复用缓存；更换地址、清空／恢复数据及预览过期后需重新识别。后台由容器内定时器驱动，无需 Cloudflare Cron。

最多 500 个清单成员、清单最多 1 MiB、单模块预览／导入／自动下载最多 10 MiB；合集每批最多两个下载，游标和快照持久化，重启可继续。相对 URL 按清单地址解析。远程 JavaScript 只作为文件读取，不执行。

单模块按内容哈希更新，不依赖版本号。使用 ETag／Last-Modified 条件请求；只有本地文件完整时才接受 304，否则重新下载补齐。来源编辑保留原映射，类型不能切换；新内部 ID 不同需要确认，本地模块来源 URL 在新内容成功发布后才改变。单模块条目内部标记 `single` 不作为播放器中的模块 ID。

可编辑来源名称（独立于模块标题）、暂停／恢复、取消。相同完整 URL 复用现有订阅，不重启已暂停的来源。取消仅移除该来源，不删除模块；其他启用来源仍可能更新同一模块。

## 身份和合集

- 同一个源内优先按远程 ID 保留本地模块身份，远程 URL 改变不会重新生成模块 ID。
- 相同完整 URL 可复用本地模块；不会仅因同名而合并无关来源。
- 更新保留 widget ID、备注、分组、排序和所有已有合集引用。
- 普通“我的合集”不会自动加新模块，只有旧版 opt-in autoAll 保持全量追加。

## 保护

- 下载失败、网页/JSON 错误页或超限响应保留最后有效文件与元数据。
- 上游删除仅标记条目已下架，不删除本地模块和自选合集引用。
- 暂停、删除、重置、恢复备份会使在途租约失效，迟到的下载不得写回。
- 下载在数据库事务之外进行；页面和本地编辑不会等待网络完成。写入前重新读取当前维护模式、备注等，并在短事务内发布。
- 同步状态显示开始/完成时间、处理进度、新增/更新/失败/下架数量及错误。暂停后不会继续自动下载。

删除订阅源不删除已入库模块。自动同步依赖容器保持运行以及来源 DNS/网络可用；停机期间不会唤醒宿主机。后台更新后 Rex 客户端仍可能需要手动刷新缓存。

默认只允许公网来源。管理员可在部署 `.env` 中配置 `TRUSTED_SOURCE_ORIGINS`，精确允许可信内网 origin；清单与每个模块 URL 独立检查，重定向不会继承上一跳的信任。移除白名单后，后续下载失败但保留最后有效模块，不改变已有合集。配置不保存在备份或数据库中，完整规则见 [TRUSTED-SOURCES.md](docs/docker/TRUSTED-SOURCES.md)。

3.0.2 的 `SOURCE_ADDRESS_CHECK=false` 可统一关闭地址范围限制，兼容 Fake-IP，清单、成员、手动和后台更新及重定向一致生效；不是只放开首次导入。关闭模式无需逐个加域名，HTTPS 证书、协议、凭据、超时、大小和内容检查仍有效。此模式可请求容器可达的内网/回环/特殊地址，仅使用可信来源。重新开启不会删除已有模块，后续失败保留旧版本。见 [ADDRESS-CHECK.md](docs/docker/ADDRESS-CHECK.md)。

旧 Docker 2.1 订阅源和条目一次性迁移，不生成新模块或合集地址。3.3 不自动接管旧单链接；在订阅页「整理已有单链接来源」预览并逐批确认（最多 10 条），不下载文件、不改变模块 ID 或合集引用。手动维护模块登记为已暂停来源，仍须明确恢复并取消模块的手动维护才能自动更新。新添加单 JS／加密链接默认登记为启用来源。

分享别名和单模块来源随 format 7 备份导出；恢复兼容旧 format 1–6，清空／恢复会使预览及在途同步失效。升级与回退见 [UPGRADE.md](docs/docker/UPGRADE.md)。
