# 从一段模块代码，到一套可部署、可协作的 Capy/Rex 工作台

**让模块管理不再散落在链接、脚本和聊天记录里。**

Capy/Rex 模块项目把模块管理平台、两种部署路线和两套 AI 技能工作流整理成一份清晰、可独立使用的发布包。无论你是想搭建自己的模块库、托管公开安装链接，还是让 AI 协助分析和迁移模块，都能从适合自己的入口开始。

## 一个项目，四种交付

### Docker 部署版｜把模块中心放在自己手里

面向 NAS、家庭服务器和 VPS。提供管理员后台、模块与文件管理、Rex 合集链接、公开页面、投稿与开发者管理流程，以及浏览器端静态检查器。数据保存在本地挂载目录，便于自行管理和备份。

适合希望掌握服务运行环境和数据位置的使用者。默认示例端口为 `8080`，可按部署环境配置域名和 HTTPS。

### Cloudflare 部署版｜把公开入口放到边缘网络

基于 Cloudflare Workers 与 SQLite Durable Object，提供管理页面、模块与合集链接、订阅同步、定时任务、备份恢复和文件管理，不需要自备常驻服务器，也不需要填写 D1 或 KV 编号。

适合希望快速建立公开模块入口、并愿意在 Cloudflare 账户中管理服务的使用者。Cloudflare 版本与 Docker/NAS 版本的功能范围不同，投稿审核、开发者账户、公开 Capy 分类页和 NAS 在线检查器没有接入 Worker 路由。

### 芜湖模块开发工作台 V2｜聚焦 Rex 与 Capy 模块

可移植的 Agent Skills 技能包，帮助 AI 助手处理 Rex 与 Capy 模块的分析、迁移、编写、修复和参数整理，并覆盖 Worker、NAS、Docker、VPS 等部署讨论，以及分层验证流程。

V2 加入能力证据分级、REXENC 静态结构检查和封面处理边界说明。它不会执行未知模块，也不会凭空补出播放器 API 或保证互转后在所有播放器版本中可用。

### 芜湖 AI 通用 PJ V1｜编程与研究的通用工作台

独立于 Capy/Rex 的通用技能包，提供编程调试、软件静态分析、授权安全审计、AI 应用防御评估、自动化排障、研究写作和技能工程等任务入口。适合在支持 Agent Skills 的宿主中按任务调用。

两套技能可以分开安装。一个专注模块工作流，一个面向更广泛的编程与研究任务。

## 从管理到交付，形成完整工作流

```text
整理模块与链接 → 创建公开入口或合集 → 按需部署服务
        ↓                         ↓
AI 辅助分析、迁移与编写 → 静态检查与分层验收 → 发布与维护
```

Docker 版适合本地掌控服务和数据；Cloudflare 版适合边缘托管公开入口；模块工作台与通用 PJ 技能则把 AI 协作流程带到支持技能的开发环境中。你可以只使用其中一个，也可以按自己的工作方式组合使用。

## 项目边界与验证说明

- 模块静态检查用于发现代码和元数据问题，不能代替 Capy 或 Rex 播放器中的实际运行验证。
- Rex/Capy 本地封面解密能力尚无充分依据；当前加解密入口指向外部服务。提交内容前应了解服务方的数据处理方式。
- REXENC v2 的结构可作静态识别，但本项目没有解密用户样本，也没有暴力尝试隐藏密钥。
- 自动化回归、配置解析、Worker bundle 检查和 ZIP 完整性检查已通过，详情见《审计报告.md》和 `SHA256SUMS.txt`。
- 本次没有执行 Docker 镜像实际构建、Cloudflare 账户实际发布、播放器 App 实机测试或服务端加解密往返验证。这些项目需要在目标环境中单独验收。
- 清洁发布包移除了运行数据库、备份、日志、`.env`、私钥和生产凭据。部署时请按各自说明创建本地配置。
