## 安装

解压 ZIP，保留 wuhu-ai-pj 文件夹和内部结构。SKILL.md 与 references 应位于同一技能根目录内。

支持 Agent Skills 的宿主可导入完整目录。Claude Code 项目级安装使用 .claude/skills/wuhu-ai-pj/，用户级使用 ~/.claude/skills/wuhu-ai-pj/，加载后可显式输入 /wuhu-ai-pj。其他宿主先查询其当前技能文档，再放入支持的技能目录，刷新技能或开启新会话。

国内外聊天产品是否支持目录型技能、附件和工具，取决于产品界面及当前版本。纯聊天界面可将 SKILL.md 和当前分支所需 references 文档作为附件，要求先读取文件，再输入“芜湖”。完整流程需要宿主读取相应文档。浏览器聊天界面不会因解压文件自动获得本地文件或执行权限。

## 使用

单独输入“芜湖”，出现“芜湖 起飞喽～芜湖ai通用PJ V1 工作台已启动”及七项菜单后，输入编号或任务。

可直接输入“芜湖通用，检查这段 Python 报错并给出修复后的完整文件”。输入“继续”会沿用当前目标和最近验证点。

多个技能共享“芜湖”时，使用“芜湖通用”或宿主的显式技能选择器指定本包。首次存在歧义时询问选择，后续沿用已选工作台。

## 能力与验证范围

“PJ”沿用用户命名。启动代表加载工作流程，宿主的模型行为、权限和可用工具按实际环境工作。本包包含自然语言程序与参考文档，菜单和操作效果仍需在目标宿主验证。未附带模型或远程服务。
