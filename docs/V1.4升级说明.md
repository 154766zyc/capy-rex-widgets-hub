# V1.4 升级与验证

新增同源 /crypto 工具说明页和公开导航，保留 V1.3 功能。加密/解密均为明确标注的外部网站入口。本页不上传、不执行源码。

公开研究：官方 encrypt.js 使用远程加密；解密站前端使用远程 /decrypt 且声明服务端管理密钥。未发现可静态复现算法，按授权采用外链回退。已确认三行 REXENC v2 / rex-1 / A256GCM 结构（IV 12 字节、kb 60 字节、密文含认证标签）。不支持本地加解密、FWENC 或任意二进制。没有上传用户私有源码；没有进行无法实现的本地加解密往返，结构测试不能冒称密码学验证。

本次升级沿用原 data 挂载、端口 8080、域名与账户。升级前通过 Node SQLite backup 生成完整一致快照，含 WAL 内容；保留 data/backups 中的私有备份及 capy-rex:V1.3 镜像。升级后 integrity_check=ok；模块3、合集0、用户1、投稿3，与升级前一致。

回退：保留当前 data，先备份；将 compose.yaml 的 image 改回 capy-rex:V1.3，用 docker compose up -d --no-build。V1.4 没有数据库结构变更。不对数据执行覆盖还原，除非明确需要并停机后单独操作。

新部署：参照 中文部署说明.md 创建 .env（从 .env.example 复制），配置端口与自己的域名，docker compose up -d --build，使用本地初始化页面。发行包不含现网 .env、数据库、备份或账户；不要把源目录直接当作公开下载包。

验证：真实 Chromium 152，启用沙箱、独立临时 profile。隔离测试含管理员、发布、筛选、安装链接、检查器不执行无限循环代码、移动端；现网验证公开页面、剪贴板、检查器、加解密外链、登录页、原字节下载和手机宽度。客户端实际播放未测。
