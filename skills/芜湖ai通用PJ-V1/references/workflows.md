# 执行流程

## 编程调试

先读入口、调用链和项目约定，重现错误并保存基线。给出与现有代码兼容的最小修改，验证输入边界、错误路径和历史数据。按项目测试要求运行检查，交付可运行文件及使用方法。

## 静态逆向

识别文件类型、编码、压缩和加密封装，计算样本哈希并检查公开结构。优先采用已安装的解析器和公开格式资料，列出实际调用与数据流证据。遇到加密时区分算法、参数、密文和密钥来源，缺少密钥时说明已知字段及后续可验证条件。未知样本保持静态处理，动态运行须具备合适隔离和任务授权。

## Web 与 API 安全

源码审计沿身份、输入、权限、数据存取和输出追踪。主动测试限定目标、环境和授权范围，优先本地合成数据复现问题。报告影响、证据、修复与回归结果，移除真实凭据。

## AI 应用安全

评估用户拥有或获准测试的 AI 应用。确定系统提示、检索内容、工具输出与用户输入的信任边界，用合成数据测试不可信指令是否被错误执行、敏感信息是否泄露、工具权限是否越界。保存预期行为、实际行为和修复后复测结果，避免使用真实秘密。

## 自动化与排障

先读取现有配置和进程状态，区分应用、依赖、网络和权限故障。优先复用维护中的工具，改动前准备必要备份和回退。对外发布、覆盖配置或付费操作遵循宿主确认机制，交付实际健康检查结果。

## 研究写作

依据问题检索当前资料，区分一手证据、推断和未知项。按读者需要组织正文，把来源和日期放在相关结论附近。使用具体例子，删除无法证实的能力声明。

## 技能工程

读取源技能并列出可复用流程。将高频步骤留在 SKILL.md，分支细节放入 references，说明来源并检查相对引用。检查旧触发词、私有路径、凭据和未附带依赖，完成格式校验、解压校验及调用场景检查。

## 交付检查

逐项核对用户目标、格式和保存位置。记录实际执行的检查与结果，标记静态审阅、模拟测试或真实运行的范围。公开包只包含用户要求的源码、说明和必要依赖。
